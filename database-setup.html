Database checklist

Set up the database before testing ESP32 cloud connection.

The ESP32 sends readings to a Supabase Edge Function. The function verifies the device token, calculates queue status and updates the public queue tables.

1. Create the Supabase project

Use one project for the whole website.

Required
A

Create project

Open Supabase, create a new project and wait until the database is ready.

B

Copy URL

Project Settings → Data API / API. Copy the project URL.

C

Copy anon/public key

Use only the anon or publishable key in the website. Never put the service_role key in frontend files.

app-config.js: window.AIOT_CONFIG = { storageMode: "supabase", supabaseUrl: "https://YOUR_PROJECT_REF.supabase.co", supabaseAnonKey: "YOUR_ANON_OR_PUBLISHABLE_KEY", deviceIngestFunctionUrl: "https://YOUR_PROJECT_REF.supabase.co/functions/v1/device-ingest" };

2. Run the database schema

This creates all tables, views, indexes and Row Level Security policies.

SQL
Supabase Dashboard → SQL Editor → New query 1. Open supabase_schema.sql from this website folder. 2. Copy the full file. 3. Paste it into SQL Editor. 4. Click Run. 5. Confirm these tables exist: profiles service_partners location_configs service_location_surveys devices device_readings camera_readings service_time_events queue_statuses queue_status_history 6. Confirm the public_queue_statuses view exists.

If the SQL was already run before, it is safe to run the included schema again because it uses if not exists and replaces policies/views where needed.

3. Deploy the Edge Function

The ESP32 must call the function, not the database table directly.

Device ingest
Function folder: supabase/functions/device-ingest/index.ts Deploy command: supabase functions deploy device-ingest --no-verify-jwt
JWT verification must be off for this function because the ESP32 does not log in as a Supabase user. The function uses the custom x-device-token header instead.
Function URL format: https://YOUR_PROJECT_REF.supabase.co/functions/v1/device-ingest

4. Configure the website

Make the website use Supabase instead of local demo storage.

app-config.js
Open app-config.js and set: storageMode: "supabase" supabaseUrl: "https://YOUR_PROJECT_REF.supabase.co" supabaseAnonKey: "YOUR_ANON_OR_PUBLISHABLE_KEY" deviceIngestFunctionUrl: "https://YOUR_PROJECT_REF.supabase.co/functions/v1/device-ingest"

The website uses the anon/public key for browser login and public queue reads. The Edge Function uses Supabase function secrets on the server side.

5. Register ESP32 and generate code

The token links one physical board to one Service Partner location.

Open Device Registration
Device Registration steps: 1. Login as Service Partner. 2. Complete Setup Survey. 3. Open Device Registration. 4. Register ESP32 device. 5. Copy or auto-fill the generated token. 6. Enter Wi‑Fi SSID and password exactly. 7. Confirm function URL ends with /functions/v1/device-ingest. 8. Keep safe default pins: 27, 26, 25, 34. 9. Generate and download the .ino file. 10. Upload it in Arduino IDE. 11. Open Serial Monitor at 115200 baud.

Serial Monitor success checklist

Use these lines to know the ESP32 is correct.

Success
ESP32 connected to Wi‑Fi. IP address: 192.168.x.x Local debug server started. Cloud push code: 200 Cloud push OK. Database should update shortly.

After this, open Service Control Hub or Public Queue Finder and refresh.

Error decoder

Most problems can be found from Serial Monitor.

Fix guide
ssid_not_found -> wrong SSID or 5 GHz network connect_failed -> wrong password HTTP -1 / timeout -> internet, DNS, SSL or endpoint issue Cloud 401 / 403 -> wrong token or inactive device Cloud 404 -> wrong function URL or function not deployed Cloud 500 -> schema/function/database error last_seen not update -> token or Edge Function problem Public page empty -> public listing/setup approval/status problem

Security rules

Use these rules for a safe public model.

Do not skip
Never expose: - Supabase service_role key in app-config.js - database password - generated ESP32 device token - Wi‑Fi password Allowed in frontend: - Supabase project URL - anon/public key - public queue status view Protected by Edge Function: - device token verification - device_readings insert - queue_statuses update - queue_status_history insert
